# РЕМОНТФОРМА — Beget Free

Эта папка содержит серверную часть для переноса сайта РЕМОНТФОРМА с Vercel на Beget Free.

## Цель

- сайт остаётся в GitHub;
- на Beget размещается публичная копия сайта;
- калькулятор работает через локальный PHP API;
- URL API сохраняется как /api/calculate;
- позднее сюда добавляются Telegram/MAX webhook и постоянное хранение сессий в MySQL.

## Что нужно сделать на Beget

1. Создать бесплатный хостинг.
2. Создать сайт и PHP 8.x.
3. Загрузить содержимое репозитория в корень сайта.
4. Создать MySQL базу — она понадобится для следующего этапа.
5. Скопировать beget/config.example.php в beget/config.php и заполнить секреты только на сервере.

Не добавляйте реальные токены в GitHub.

## Домен

На первом этапе можно тестировать на бесплатном адресе Beget. После проверки подключается собственный .ru/.рф домен без переделки приложения.

## Архитектура

GitHub -> Beget -> site/index.html + api/*.php

Vercel на первом этапе можно оставить включённым как резервный вариант. После проверки Beget переключаем основной домен.

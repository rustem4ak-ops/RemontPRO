# Вариант 1 — РЕМОНТФОРМА + Bitrix24 Open Line

Этот вариант оставляет **@RemontFormaBot подключенным к Bitrix24**, а калькулятор работает как чат-бот внутри Открытой линии.

Telegram → Bitrix24 Open Line → «РЕМОНТФОРМА Калькулятор» → общий pricing engine → CRM.

Это решает проблему с двумя владельцами Telegram webhook: Telegram остаётся подключённым к Bitrix24, а логика калькулятора запускается через официальную платформу чат-ботов Bitrix24.

## ENV

В Vercel нужны:

- `BITRIX24_WEBHOOK_URL` — уже используемый входящий вебхук Bitrix24.
- `BITRIX_CHATBOT_TOKEN` — отдельный секрет чат-бота Bitrix24, не Telegram-токен. Любая случайная строка до 40 символов.

## Один раз после деплоя

Откройте:

`https://remont-pro-nine.vercel.app/api/setup-bitrix-chatbot`

Endpoint зарегистрирует бота и команды `/calculator` и `/manager`.

После этого в Bitrix24:

CRM → Клиенты → Контакт-центр → Telegram → ваша Открытая линия → Чат-боты → выбрать **РЕМОНТФОРМА Калькулятор**.

Включить запуск чат-бота на первом сообщении.

## Что умеет

- Квартира / Дом / Коммерция.
- Площадь и площадь санузла.
- Электрика.
- Сантехника.
- Санузел.
- Плитка.
- Ламинат / кварцвинил.
- Плинтус.
- Стены.
- Чистовая электрика и сантехника.
- Клининг.
- Вывоз мусора.
- Итог и цена за м².
- Новый расчёт через `/calculator` или текст «Рассчитать заново».
- Передача менеджеру по слову «менеджер».
- Номер телефона → поиск существующего контакта → новая сделка, привязанная к контакту.

## Важное ограничение

Telegram-клавиатуры, созданные средствами Bitrix24, не гарантированно отображаются как нативные Telegram-кнопки. Поэтому основной надёжный способ перезапуска — команда `/calculator` или текст «Рассчитать заново». Сам Telegram-бот при этом остаётся владельцем канала Bitrix24, а история переписки сохраняется в CRM.
